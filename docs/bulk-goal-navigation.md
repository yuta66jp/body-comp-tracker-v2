# Bulkの増量ペース表示

Issue #767。Bulkは早期に目標体重へ到達することではなく、保存済み月次計画への適合を評価する。

## 表示・計算

- BulkのKPIは「増量ペース」。予測到達日とバッファは表示しない。目標日・残日数は維持する。
- KPI・目標達成ナビ・直近7日サマリーは、page.tsxで一度計算した`calcBulkWeeklyPlanPace`の結果と共通表示定義を使う。
- 実績ペースは直近7日の平均体重から前の7日の平均体重を引いた値。計画ペースは、実績と同じ記録日に補間した月次計画体重の平均差。
- ナビの計画との差は実績ペース−計画ペース。`kg（前週比）`で表示し、計画・実績・差は小数2桁。計算・判定は丸め前の値を使う。
- 増量ペース評価、KPIの体重トレンド、ナビの基準体重は進行中シーズン開始日以降の記録だけを使う。
- 実績ペースの数値と現在体重KPIの増減は通常色。ナビの差・状態バッジは計画内=緑、緩め/やや速い=黄、超過/増量方向外/計画要確認=赤、判定待ち/記録不足=グレー。
- 閾値と月次計画の保存上限は既存Bulk週次仕様を変更しない。「先行」「遅れ」「順調」で速い増量を評価しない。

## 判断を保留する条件

- シーズン開始日を含め14日未満は「判定待ち」。最短判定開始日と各7日窓の実際の記録日数を表示する。
- 14日目以降も各7日窓の記録が5日未満なら「体重記録不足」。ペース値・差は表示しない。
- 不正な月次計画・期限超過は既存計算の`plan_check`。計画を作成できない場合も「月次計画を確認」とし、Cutの順調判定へ戻さない。
- 目標日未設定・本日・期限終了は日付の案内を併記する。体重到達や日付経過でシーズン状態を自動変更しない。

## 調整案内と月末目標との差

- Bulkの調整欄は同じペース状態に基づく案内。前週比は記録日平均との差であり、固定7日間の傾きとみなしたカロリー自動換算・目標摂取数値は表示しない。
- 月末目標との比較は「月末目標との差（最新体重）」として分離する。0.2kg超〜0.5kgは「月末目標を上回る」、0.5kg超は「月末目標を超過」。既存閾値は維持する。
- 月末目標超過だけで週次の「増量ペース超過」とは判定しない。週次が判定待ち/計画内でも月末目標の注意は残す。
- 月次欄の残必要ペースはBulkでは表示しない。短い残日数による追い込み/減量の示唆と、ペース欄との比較基準の混在を避ける。
- Cutは従来の予測到達日・バッファ・14日回帰・kg/2週表示・数値のカロリー調整を維持する。

## 確認項目

- 計画内、緩め、やや速い、超過、逆方向の各状態でKPI・ナビ・週次のラベルが一致する。
- 超過時に実績/差が緑にならず、先行・順調・調整最小限と案内されない。
- 開始直後、欠測、計画未設定/不備、期限超過、月末目標超過を区別する。
- シーズン外の記録が計算へ入らない。Cutの表示を維持する。
- PC/狭幅のレイアウトと関連UI結合テストを確認する。
